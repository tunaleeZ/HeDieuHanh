SCRUM-87 / 6.1 — Per-container CPU fields through cont_info

int id, proc_count, max_proc, active; uint64 cpu_period_ticks,
cpu_quota_ticks, cpu_used_ticks; int max_pages, pages_used. The user copy is
in user/user.h and matches the kernel ABI field order/types/alignment.
