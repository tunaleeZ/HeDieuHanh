Observed A/B iteration ratios: 22.03%, 21.55%, 22.39%. The quota-bound
container received materially less CPU work each time, and host progress
continued throughout the 200-tick workers' run. These are loop iterations,
not calibrated CPU cycles; the expected ratio is approximate.

No deadlock or busy-loop was observed in these runs. Timer-interrupt charging
is a soft approximation: an interrupt counts as one CPU tick; multi-hart
simultaneous scheduling and timer resolution can overshoot quota. The test
does not specifically exercise throttling while a process holds an inode
sleeplock; that wait-risk remains unverified. `ticks` sampling is unlocked,
and timer drift is not quantified here.
